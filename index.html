🔭 외계 행성 탐사 원리학 (지구과학 기준)

1. 시선속도법 (Radial Velocity Method / 도플러 효과)

행성이 항성을 돌 때, 항성도 공통 질량 중심을 기준으로 미세하게 회전합니다. 관측자 쪽으로 다가올 때 항성의 스펙트럼 흡수선이 청색 편이(Blueshift)를 일으키고, 멀어질 때 적색 편이(Redshift)를 일으킵니다.

2. 식현상법 (Transit Method / 광도변화)

행성이 관측자와 항성 사이를 지나갈 때 항성의 빛 일부를 가려 전체 광도가 일시적으로 감소합니다. 감소 폭 \(\Delta F = (R_p / R_s)^2\)을 측정하여 행성의 크기를 정밀하게 측정할 수 있습니다.

3. 미세중력렌즈법 (Gravitational Microlensing Method)

먼 배경별 앞을 행성을 거느린 전경별(렌즈별)이 지나갈 때, 렌즈별의 중력으로 시공간이 휘어져 배경별의 빛이 집광되면서 밝아집니다. 이때 렌즈별 주위의 행성 중력에 의해 밝기 곡선에 짧고 날카로운 미세 피크(Anomaly Peak)가 덧붙여 나타나 외계 행성을 발견합니다. 궤도 경사각에 무관하며 중심별에서 먼 행성도 검출할 수 있으나 일회성 현상이라는 특징이 있습니다.

4. 시선방향과 공전궤도면이 이루는 각도 (\(\theta\))

  • \(\theta = 0^\circ\) (시선방향과 평행 / Edge-on): 시선속도 변화 최대, 식현상 발생.
  • \(\theta = 90^\circ\) (시선방향과 수직 / Face-on): 시선속도 변화 0, 식현상 미발생 (단, 미세중력렌즈는 검출 가능).
